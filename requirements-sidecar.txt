# Bumping a version: rebuild the sidecar, re-run the smoke test
# (echo '{"cmd":"hello",...}' | sidecar.exe), and verify bundle size
# is in the expected range.

# range constraint.

# requests 2.34.2 picks up CVE-2026-25645 (insecure temp file reuse).
