# 回傳結構、邊界值與錯誤碼 (Shape, Bounds, Codes)

## 1. 回傳結構：貼原文，嚴禁抹平巢狀層
- 宣稱任何回傳欄位，必須以該處 return / _ok(...) / _err(...) / Ok(...) 的原文為準並貼進證據欄。沒有展開回傳值就不得列欄位，填未查證。
- 嚴禁抹平巢狀層。巢狀結構必須完整保留層級，不得寫成平鋪欄位。
- 內部狀態賦值不是回傳證據。例如賦值給 state 欄位不能證明回傳結果中包含該欄位。

## 2. 邊界值：引用常數定義行與運算式，兩者缺一不可
- 任何上限／下限／預設值宣稱，證據欄必須同時包含常數定義行與使用它的運算式。
- 嚴禁採信註解、docstring 或測試資料。註解與測試樣本不等於實際規則。
- 預設值不是上限。宣稱上限必須把 clamp 兩端與計算公式一起引用。

## 3. 前置條件與錯誤碼：逐條對守衛語句，不得由 HTTP 狀態碼推導
- 前置條件是完整性宣稱。列出前必須掃過進入點至主邏輯間的每一個提前 return / 守衛條件。
- 錯誤碼必須是程式碼實際產出的字串，用該字串本身搜尋並命中產生它的行。
- 嚴禁由 HTTP 狀態碼推導錯誤碼名稱。錯誤碼分類表需窮舉所有錯誤碼呼叫，不得隨意推論。

## 4. 證據指令必須證明「那個特質」
- 指令必須證明主張的特質：數值規則需命中常數與比較式，行為需命中實作代碼，集合完整需證明沒有第 N+1 項。指令無法證明時填未查證。
